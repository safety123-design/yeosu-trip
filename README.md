# 여수 · 우리 여섯의 네 밤 다섯 날

2026.07.06 – 07.10 · 4박 5일 여수 힐링여행 안내 페이지

전문 에디토리얼 스타일의 단일 HTML 페이지입니다. CSS·JavaScript가 모두 `index.html` 안에 인라인으로 내장되어 별도 빌드나 의존성 없이 동작합니다.

## 구성

- **미리보기** — 오동도·순천만·백리섬섬길 등 주요 풍경
- **수영장** — 라마다 인피니티풀 / 베네치아 루프탑풀 운영시간·요금
- **호텔** — 라마다플라자(돌산) → 베네치아 호텔 숙박 안내
- **일자별 일정** — Day 1~5 타임라인
- **배편** — 신기항 ⇄ 여천항(금오도) 하계 시간표
- **맛집** — 여수·순천만·광양 향토 맛집
- **영상** — 여수 여행 영상 모음
- **여행 팁** — 폭염·수분·수영장 안전 등 안내

## 특징

- 모바일 우선 반응형 레이아웃
- 글자 크기 조절(가 / 가 / 가, 설정 저장)
- 스크롤 리빌 애니메이션
